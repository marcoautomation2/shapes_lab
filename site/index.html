Educational library

Shapes Lab

A teaching library about sealed types: grid shapes with area, perimeter and bounding boxes, written to be read.

  • rank worker100
  • education
  • geometry
  • sealed types

https://marcoautomation2.github.io/shapes_lab/shapes_lab_edu_lib.zip

How to use it

  1. Press Copy URL.
  2. Import the URL into a Fearless project with the Fearless manager. The code of the project can then use the library.
  3. Write use shapes_lab.TypeName as TypeName; in the rank file of the package that needs the library.

The package of the project needs a rank higher than worker100. Every app qualifies.

The zip also works by hand: copy the zip, zipped or unzipped, into the project.

What is inside

  1. shape.fear: a sealed type and its .match.
  2. shapes.fear: factories that hide the kinds.
  3. bounds.fear: working with lists of sealed types.

Every method has an example in its doc comment. The folder example of the source holds a small app that uses the library.
